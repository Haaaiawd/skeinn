## Bugs found and fixed this session (both real data-loss paths)

1. **Clear never persisted.** `scheduleImmediateSave()` was an alias for the *debounced* `flush()`, which
   returns immediately when nothing is pending. Clear / Undo / Import rewrote the screen but never wrote
   storage, so **a reload resurrected the text the human had just cleared**. Fixed in `src/ui.js`:
   `scheduleSave(); flush();`.
2. **IndexedDB degrading to memory wrote nowhere.** When the IDB adapter fell back to memory mid-session,
   `ui.js` kept writing to it and skipped the `localStorage` cache entirely. Now the durable write is gated
   on `IDB.mode !== 'memory'`, so the local tier catches the draft.
3. Test-harness bug (not product): the reusable `fakeStorage` in `edgecases.test.mjs` captured `failOn` at
   construction, so a mid-session quota flip was invisible. Now it reads a mutable flag.

`index.html` was rebuilt after each fix; `build.mjs --check` is green.
